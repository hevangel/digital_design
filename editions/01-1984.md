# Edition 1 — 1984

**M. Morris Mano, Digital Design**, Prentice-Hall, 1984. Representative ISBN 0132123339 / 9780132123334; Google Books catalog records 492 pages.

## Teachings retained in the companion

- Binary and other radices, signed representation, complements, codes.
- Boolean algebra, truth tables, Karnaugh-map reasoning, NAND/NOR equivalents.
- Combinational blocks: adders, code converters, decoders, multiplexers.
- Clocked state elements, counters, registers, state-transition tables, control.
- Asynchronous sequential analysis, physical gate families, and period-appropriate IC laboratories are important historical context; don't assume today's synchronous FPGA practice was universal in 1984.

## How the code relates

All SV/VHDL examples are **modern translations**, not historical examples or copied exercise solutions. The source edition predates the widespread use of both languages. For real 74xx/TTL timing use datasheets rather than inferring delays from RTL.

# Edition 3 — 2002

**M. Morris Mano, Digital Design**, 3rd ed., Prentice Hall, ISBN 9780130621214. Some print catalogs list 2001 rather than 2002.

## Documented changes from edition 2

- **Added:** nine separate Verilog HDL instructional sections (not the same as an entire new chapter).
- **Reorganized:** combinational circuits consolidated into one chapter.
- **Reorganized:** memory and programmable logic brought together into one chapter.
- **Changed emphasis:** sequential design moves toward D flip-flops rather than primarily JK/SR devices.
- **Substantially rewritten:** Chapter 8 register-transfer-level datapath/control design.
- **Added:** Chapter 11 HDL simulation work alongside physical circuit lab work; a commercial Verilog simulator CD accompanied some copies.

## Why it matters

This is the transition from gate-drawing exercises to a model that can be simulated: infer hardware from `always` blocks (today prefer `always_ff`/`always_comb`), separate next-state logic and registers, test behavior. A test that passes in zero-delay simulation does not establish setup/hold timing.

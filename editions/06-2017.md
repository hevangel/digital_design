# Edition 6 — 2017 print / later eText and global releases

**M. Morris Mano and Michael D. Ciletti, Digital Design: With an Introduction to the Verilog HDL, VHDL, and SystemVerilog**, 6th ed., print ISBN 9780134549897 (2017); Pearson also lists later 2021 eText, ©2022 and 2018/2024 global product records. These are release/market metadata **not** editions 7–9.

## Documented evolution

- **Explicit multilingual pedagogy:** the publisher describes parallel Verilog, VHDL, and SystemVerilog paths, one of which can be chosen independently.
- **Chapter 8.13 listed as** *System Verilog—An Introduction* where 5th edition lists *Other Language Features*.
- Core chapters 1–8, then laboratories in 9 and standard graphic symbols in 10 remain represented in publisher TOCs.
- Minor subsection renamings (e.g. combinational “Analysis Procedure” vs “Analysis of Combinational Circuits”) do not prove topics were added or removed.

## Learning how to translate

| Concept | SystemVerilog | VHDL |
|---|---|---|
| 4-state signal | `logic` | `std_logic` |
| Comb process | `always_comb` | `process(all)` |
| Clocked process | `always_ff @(posedge clk)` | `if rising_edge(clk) then` |
| Unsigned arithmetic | typed `logic [N-1:0]` / explicit casts | `unsigned` from `numeric_std` |
| FSM types | `typedef enum logic` | enumerated `type state_t is (...)` |
| Assertion | `assert (...)` | `assert ... report ... severity failure` |

Do not translate SV nonblocking `<=` to VHDL variable assignment, or ignore differences in event scheduling; simulation equivalence is a testable property, not a syntactic assumption.

## Source quality and corrections

- If a page describes a 3rd book using the phrase “fourth edition,” prioritize *edition/ISBN metadata* and separately verified TOC, not that copied marketing sentence.
- TOCs support a **chapter-level** comparison. Without a full original and revised text, claims like “every transistor topic was removed” or “this edition first introduced x” are not justified.
- Please open a documentation correction with a quoted heading, ISBN, page and primary citation if a distinction changes. We do not require reproducing copyrighted pages.
